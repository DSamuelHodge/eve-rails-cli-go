# Contributors

Eve Rails CLI welcomes focused fixes, tests, documentation improvements, and examples that make fleet workflows safer and easier to operate.

Please follow the project conventions in `README.md`, `SPEC.md`, and `.github/CONTRIBUTING.md`. For code changes, include tests that demonstrate the behavior, run `gofmt`, `go vet ./...`, `go test ./...`, and `bash scripts/verify-cli.sh`, and avoid committing generated secrets or local environment files.

Contributors are recognized through Git history, pull requests, release notes when appropriate, and issue discussions. If a contribution is made on behalf of a team, include the human author in the commit metadata or PR description.
